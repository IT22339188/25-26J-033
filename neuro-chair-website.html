Project Overview

What is Neuro Chair?

Neuro Chair is a sensor-based smart office chair system designed to monitor employee wellbeing in modern IT office environments. The system collects real-time physiological data and posture information to detect stress levels using advanced machine learning algorithms.

Our innovative solution addresses critical workplace challenges including stress, poor sitting posture, reduced productivity, and health risks that employees face during long working hours.

⚡ Real-Time Monitoring

Continuous physiological data collection and analysis

📈 Trend & History Insights

Analyzes both real-time and historical data to detect long-term patterns and behavioral changes

🤖 AI-Powered

Machine learning-based stress classification

📊 Posture Detection

Advanced ergonomic monitoring and feedback

🔒 Secure

Data privacy and security focused design

The Problem & Our Solution

Addressing the gap between employee wellbeing and workplace monitoring

🔍 Research Gap / Key Problems

  • Employees experience stress and poor sitting posture during long working hours
  • Stress and posture issues often go unnoticed in real-time
  • Lack of continuous health monitoring in office environments
  • Absence of immediate feedback for ergonomic improvement
  • Reduced productivity due to stress and physical discomfort
  • Increased health risks including back pain, muscle fatigue, and burnout
  • Higher organizational costs due to employee absenteeism and health issues
  • No automated system for detecting and responding to wellness threats

💡 Our Solution - Neuro Chair

  • Real-time physiological data collection using multiple advanced sensors
  • Continuous monitoring with immediate stress and posture detection
  • Machine learning-based stress classification and analysis
  • Instant feedback and alerts for posture correction
  • Enhanced employee wellness and productivity tracking
  • Prevention of long-term health complications through early intervention
  • Reduced organizational costs via improved employee health and engagement
  • Automated, intelligent system for comprehensive workplace wellness

Key Technologies

Category Technology/Component Purpose
Sensors PN532 (NFC Module) User identification and access control via NFC card/tag detection
Sensors FSR (Force Sensitive Resistor) Pressure and weight distribution sensing
Sensors MLX90614 Temperature monitoring
Sensors MPU6050 (IMU) Posture and motion tracking
Sensors MAX30102 (Heart Rate/SpO2) Physiological signal monitoring
Software Machine Learning (XGBoost - Stress Detection) Classifies stress levels (Low, Medium, High) with 90.7% accuracy and F1-score of 0.906 using physiological data
Software Machine Learning (XGBoost - Posture Classification) Identifies user posture patterns with 95.0% accuracy and F1-score of 0.948 using sensor data
Software IoT Platform Sensor integration and data collection
Software Data Analytics Real-time processing of physiological signals
Infrastructure Cloud/Edge Computing Data storage and processing
